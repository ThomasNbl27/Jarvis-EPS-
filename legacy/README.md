# Code d'origine

`jarvis-eps-tkinter-original.py.txt` est le code Python (Tkinter + SQLite) tel qu'il figurait
dans le document Word de départ, conservé ici pour référence.

Il porte l'extension `.txt` parce qu'il **ne s'exécute pas en l'état** : le passage par
Word a remplacé les guillemets droits `"` par des guillemets typographiques `“ ”`, ce qui
provoque une `SyntaxError` dès la première ligne concernée. D'autres défauts de fond sont
listés dans [`../AUDIT.md`](../AUDIT.md).

L'application web à la racine du dépôt reprend l'intégralité de ses fonctionnalités.
